# 整个task最终成功预测：修订方案 v2

制定日期：2026-11-06。根据用户纠正：“我要预测的是一整个task是否成功”，
主目标恢复为原任务验收定义；当前完成与剩余成本仅作辅助预测。
本方案在v2拟合前固定；独立产物目录为`artifacts/stepwise_lr_v2`。
上一版stepwise_lr_v1和第二轮冻结比较均保留，不覆盖源数据或旧产物。

## 成功定义与监督目标

主标签`task_success = 1 - 原label = 原result.success`。
原验收要求必要写入全部满足、完整状态正确、没有历史额外/重复违规写入。
同一个已结束Session的所有前缀共享这个最终标签。
早期超时后重试并最终成功的轨迹，早期前缀也标为最终成功；
是否接受写错后修复由原验收器决定，本轮不重新定义业务成功。
当前验收器不独立检查必要读取或最终回复质量，该范围限制继续披露。

辅助头为：

- `acceptance_now`：按同一原验收器，当前必要写入、状态和历史写入是否全部通过；
  不能取代主标签，也不作为主模型的输入。
- `remaining_cost_cny`：原自然结束CNY减去当步已发生CNY。
- `remaining_tokens`：原自然结束Token减去当步已发生Token。

旧宽松状态完成、严格当前完成、最终严格成功均可用于私有核对，
但v2对外不再使用含糊的`success_continue`或把状态匹配称为最终成功。
所有监督目标只能在离线结束后制作，运行时仅输出预测值。

## 数据和复现边界

使用已封印扩展数据的train/validation；保持原父家族分区和三折CV。
原测试集已曝光，不生成新预测、不用于本轮选策。
封印加载器可以读取全表核验完整性，但实际原始轨迹提取器拒绝test。
只接受工具返回后的可决策前缀；本批第12步不作为模型决策输入。
输入仍为22列运行时特征，任务ID、模板、答案、真实目标和未来事件均禁止进入模型。
模型也不接收其他头的真实标签或预测作为新增特征。

在拟合前保存源码快照、依赖、数据和旧模型封印、目标定义、候选参数、父家族折、
指标和可选停止政策方案。使用新模块实现，保留旧模块以使旧封印可复核。
所有实际消费的原始trajectory/result在提取前后及发布前核验SHA256。
输出目录已存在则拒绝覆盖。收费请求数为0，模型参数只离线训练。

## 固定训练方案

两个LR头：C=[0.1,1,10]，class_weight=[None,balanced]，
max_iter=2000，random_state=42。
两个Ridge头：alpha=[0.1,1,10,100]，输出钳制为非负。

沿用数值插补/缺失标记/标准化和类别One-Hot，在每个拟合折内学习预处理。
每Session最多等距抽取6条拟合前缀；各头剔除自身缺失目标后，
每Session总权重相同，再归一化行权重均值为1。
留出折使用全部前缀，按Session等权评分；分类按三折Brier均值最小选参，
回归按三折MAE均值最小选参；并列取枚举第一项。
只有一个类别的拟合折记录常量概率；没有有效回归目标的头记为不可用，
不改变分折，不把缺失填0。数值线程为1。
不增加后验校准器、额外特征或新模型搜索。

## 主评价：最终task成功预测

主报告针对`task_success`，辅助指标另列，不能用当前完成AUC替代最终成功AUC。
总体前缀指标按Session等权；原标签中成功和失败两类分别明确正类含义。

- Brier、Log loss、ROC AUC、成功AP、失败AP、ECE和校准分箱。
- 固定0.5分类阈值的准确率、平衡准确率、成功/失败召回和混淆矩阵。
- 固定第1、3、6、9、11步（主时点第3步）的上述指标和存活Session分母；
  另输出全部可决策步骤，不填充已经结束的轨迹。
- 对同时存在第3、6、9步的共同Session，比较这三个时点；
  避免把随步数改变的存活人群误当作模型逐步改善。
- 按父家族、模板、工作流、故障条件分组，列明分母。
- 保存成功恢复、失败、曾经当前验收通过但最终失败等实际逐步预测示例；
  示例按预先定义的条件和Session ID排序选取，不能仅挑预测正确的轨迹。

对照为训练集Session等权成功率常量、第二轮完整LR的冻结验证预测（取1-失败概率），
以及v1的冻结success_continue验证预测；统一对照原最终task标签。
对照只能读验证预测，不能生成或读取新测试预测。
如果只更正少量训练标签导致指标变化很小，应如实报告，不声称准确率显著提升。

## 运行时预测与可选停止分离

默认`predict`及逐Session监测器只返回`p_task_success`、`p_task_failure`和辅助预测。
每步重新计算同一个最终事件的概率，不强制单调，不因暂时错误永久锁死预测。
当前验收概率再高也不会自动输出停止。
严格校验22列输入、步数递增和各Session独立状态。

单独实现可选风险停止器，只有显式指定政策才生效；
它仅在最终task成功概率低且预计剩余资源达到门槛时停止，不设完成分支。
预先枚举：

- 成功概率阈值：关闭、0.01、0.025、0.05、0.10、0.20。
- 连续命中：1、2；工具步有间隔时重置；停止后不再决策。
- 资源门槛：0、抽样训练正剩余资源50%和80%分位数。
- 有完整CNY目标和可用费用头时统一用CNY，否则全局改用Token。

去重并包括永不停止。验证误停预算为0%、1%，分母为原最终成功Session；
无论停止时状态是否已完成，风险停止原成功Session都计作误停，
不能用当前完成辅助目标或挽救数冲抵误停预算。
可行候选按验证执行资源最少选择，再依次比较误停少、捕获原失败多、
总停止少、枚举早。可选政策不改变默认仅预测行为。

单独报告停止数量、原失败告警、原成功误停、严格验收回放的成功损失/挽救、
资源节省与未知费用。默认仅预测、旧第二轮主政策及v1主政策作为描述性对照。
停止收益不作为主预测指标，离线回放不代表实际在线收益。

当前已完成后继续破坏的最终失败、第12步才成功、标签/未来信息隔离、
父家族隔离、测试分区拒绝、目标缺失和成本扣除、序列化、
