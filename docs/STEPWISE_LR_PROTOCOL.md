# 逐步完成与剩余成本模型：开发方案 v1

制定日期：2026-11-06。用户授权沿用LR，增加当前完成、剩余成本等预测目标。
本轮是已查看第二轮结果之后的探索性开发；现有验证集也已被使用过。
只训练、开发与验证，不生成原测试集的新预测，不将验证结果称为独立测试或在线收益。
原始数据、旧标签、第二轮冻结模型、报告与测试产物保持不变。

## 数据与信息边界

使用 `artifacts/expanded_dataset_v1` 的train/validation分区。
沿用既有父家族分组与3折CV；不随机拆分前缀、不重划测试集。
封印加载器可以核对整个数据集文件的完整性，但新目标提取器拒绝读取test原始轨迹，
训练与开发入口拒绝test输入；新增测试预测数及收费请求数均为0。

输入继续限定为原22列运行时特征。任务ID、模板、父家族、故障条件、预期写入、
当前真实完成、剩余真实成本和未来结局均不能输入模型。
私有任务答案、轨迹后续及最终结果仅用于制作监督目标和回放评价。
所有目标按session_id/step对齐，仅工具返回后的可决策前缀进入训练。
第12步可以提供未来结局证据，但不作为暂停决策点；初始状态另行记录，不生成第0步模型输入。

## 逐步目标与恢复语义

每个工具步重新回放实际已应用写入，生成下列目标；原label字段仅作兼容诊断保留。

| 目标 | 定义 | 模型 |
| --- | --- | --- |
| complete_now | 当步全部必要写入已出现，且完整状态与预期相同 | Logistic Regression |
| success_continue | 按原执行策略继续到自然结束时，上述完成条件是否满足 | Logistic Regression |
| remaining_cost_cny | 自然结束CNY减去当步已发生CNY | Ridge线性回归 |
| remaining_tokens | 自然结束Token减去当步已发生Token | Ridge线性回归 |

complete_now不额外要求历史违规数为0，因而允许先写错、再改回正确状态的恢复。
额外通知、事件和备注仍保留在完整状态中，当前工具不支持撤销，不会仅因其他字段改对就被忽略。
即使状态相同，尚未执行完任务明确要求的写入次数也不能标为完成。
列表顺序仍属于状态对照的一部分。

另存strict_complete_now、strict_final_success、历史违规数、首次违规步、
初始完成状态和停止时损失/保留/恢复完成等私有评价字段；不把合规和状态完成混成一个标签。
必要读取尚未由现有验证器独立核验，因此这里的“完成”仅指必要写入与完整状态，
不能声明已经覆盖全部业务语义。

success_continue描述当前轨迹在原策略下的结局，不代表其他后续行动的成功概率。
未观察到恢复不能证明任务不可恢复；模型自己的告警也不能充当训练真值。
累计费用与Token均保留当步已发生部分；缺失目标保持缺失，严禁填0。
小于1e-8的累计浮点误差可钳制为0，实质负剩余值必须报错。

## 训练与评分

每Session最多按步骤等距抽取6条前缀拟合，不依赖目标抽样。
拟合行权重为该Session采样行数的倒数，再归一化为平均权重1；
CV评分使用全部留出前缀，权重为该Session有效评分行数的倒数。
预处理沿用数值插补/缺失标记/标准化和类别One-Hot，只在拟合折学习。

- 两个LR头：C为0.1、1、10；class_weight为None、balanced；max_iter=2000；种子42。
  按3折Session等权Brier均值最小选择，因后续规则使用概率。AP、ROC AUC和校准另列。
  若某拟合折目标只有一个类别，明确记录并使用常量概率，不重新分折。
- 两个Ridge头：alpha为0.1、1、10、100；预测值钳制为非负。
  按3折Session等权MAE均值最小选择，另报RMSE、偏差与训练常量中位数对照。
  缺失目标行仅从该头拟合/评分中排除，不改变其他头；整头无有效数据时记为不可用。
- 并列选择预先枚举的第一项。数值线程上限为1。
- 保存每折评分、最佳候选OOF预测、全训练和验证逐步预测、模型二进制及哈希。

当前完成和继续成功是两个不同目标：前者可以在同一Session内随步骤改变，
后者保持该次原策略最终结局。原本“所有前缀共享最终标签”是结局预测，
新增目标补充停止时的成果与成本，不将早期正常步骤直接解释为失败。

## 可运行的逐步控制器与验证选策

每个Session建立独立控制器，按工具步接受22列特征，输出四个预测值及continue/stop和原因。
控制器不访问任务答案或后续轨迹；同一Session内步骤必须递增，步数有间隔时重置连续计数。
停止后的控制器不继续决策。

候选规则有两个分支：

1. 完成分支：当前完成概率至少为阈值，满足连续证据要求时暂停并标为completion。
2. 低继续收益分支：继续成功概率不高于阈值，预测剩余资源不少于门槛，
   满足连续证据要求时暂停并标为low_continuation。

完成分支优先；两分支分别累计连续命中次数，不能混合一次完成命中和一次低收益命中。
候选完成阈值为关闭、0.9、0.95、0.975、0.99、0.995、0.999；
继续成功阈值为关闭、0.01、0.05、0.10、0.20；
连续命中次数为1、2；资源门槛为0、抽样训练正剩余资源的50%和80%分位数。
包括显式永不停止；候选按以上枚举顺序去重。

如果训练和验证CNY目标完整且费用头可用，使用CNY门槛与费用目标；
否则整次选策统一使用Token预测、训练Token门槛与实际Token目标。费用未知不计0。
完成分支不受剩余资源门槛约束，回归预测仍返回供调用方理解预计剩余开销。

分别选择completion_only和combined两种政策，预算为原最终完成Session中
停止时尚未完成的比例不超过0%（主要开发政策）或1%（次要）。
这里明确使用完成损失约束；原严格误停率仍报告，但不把完成后停止混同于成果损失。
预算约束针对损失数量，不能用挽救数量抵消损失后再达标。

在满足预算的候选中最小化全体验证实际执行资源；并列依次选择完成损失更少、
完成数更多、停止次数更少、枚举更早的候选。
比较永不停止和原第二轮full/LR@5%的冻结政策；原政策仅在验证上按新口径重新评价，
不改变其模型或阈值。本轮不使用原测试集再次比较。
