# 冻结LR的既有测试集复评方案

制定于本轮新测试预测生成之前，2026-11-06。用户已明确授权执行。
输出独立保存为 `artifacts/early_lr_test_v1`，不修改任何既有模型、源码封印或原始数据。
这是既有测试集复评：该测试集曾用于第二轮旧模型评价，不是全新盲测。

## 固定比较对象

从 `artifacts/early_lr_v1` 加载已冻结权重：

- 对照 `frozen_v2`：22列运行时输入，LR，C=10，class_weight=None。
- 主模型 `history_payload`：48列运行时输入，LR，C=0.1，class_weight=None。
- 辅助当前严格验收LR、剩余CNY/Token的Ridge沿用冻结v2权重，两模型共享。

不重新拟合，不校准，不使用测试结果更换主模型、挑选其他变体或调整阈值。
此次不评价其余开发候选，避免把测试集变成模型选择集。
所有模型文件和政策在读取本轮测试标签、生成预测之前记录哈希并复制到新产物目录。

## 固定政策

主政策：两个模型分别沿用已由训练OOF选定的 `risk@0.01`：
最终成功概率≤0.10，即失败概率≥90%，连续两步确认，预测剩余CNY≥0。
次要政策：冻结的 `risk@0`，成功概率≤0.01，连续两步确认，同样资源门槛。
`0`、`0.01`是训练误停预算，不是测试表现保证。

同时列出预先指定的失败概率≥90%/≥80%同门槛对照和默认只预测参考。
与主政策重复的90%规则共用同一回放结果或明确标为同一政策，不据测试成绩重新选策。
成本预测不可用时不自动停止；第12步不产生新的决定；步骤间隔重置连续证据。
一条task最多记录一次首次停止。

## 数据与标签

使用 `artifacts/expanded_dataset_v1` 冻结的test分区：
1176条有效task，855成功、321失败，9288条可决策前缀；24条无效运行按原审计排除。
保留原父家族/模板分区，不随机重分，不从train或validation补充。

新增独立测试适配器，显式要求 `split=test`。
旧开发入口的train/validation限制不修改，不把test伪装成validation以复用接口。
只有按allowlist投影后的22/48列特征进入预测头，分区、ID、标签与验收事实留在外层评价表。

主标签为 `task_success=1-原label`，每条task全部前缀保持同一个最终结果。
从已冻结原始trajectory读取可观察工具事件，用原特征构建器重建22/48列，
旧22列与审计前缀逐行核对。
每个消费的trajectory/result在读取前后和结束时检查原始SHA256。
严格验收、原始违规时点和剩余资源事实通过原任务与已应用写入回放取得，仅作评价。
重放最终状态与原result必须一致，任何不一致停止执行，不静默排除样本。

## 评价与呈现

- 主预测对比：全前缀task等权；固定第1/3/6/9/11步；
  共同存在第3/6/9步的task队列。保存Brier、AUC、两类AP、Log loss、ECE、
  0.5分类混淆矩阵和召回，明确各时点存活分母。
- 报告第3/6步Brier的平均值，并保留第3步退化等负结果。
- 按父家族、模板、工作流和条件分组，同时给出task数与父家族数。
- 政策对比列：失败概率门槛、平均/中位停止步、触发停止task数、
  判失败准确率、失败覆盖率、成功任务误停率、严格成功损失/挽救、
  费用与Token节省、第3/6步前累计失败告警及首次违规前告警。
- 成功任务误停率=被停止的原成功task/855，以百分比显示；
  即使停止时已完成也计入误停，挽救不能抵扣。
- 平均停止步仅以停止的task为分母；费用节省以全部有效test原轨迹为分母。
  任一所需费用缺失则总费用节省标未知，不能按0补齐，也不因结果改用另一政策。
- 对误停task保存逐步特征/概率/验收事实，并固定使用词典序首个实例作为文字例子；
  不只挑对模型有利的轨迹。

所有收益均为原轨迹回放估算，不含监测器开销，不推断真实线上效果。
少数父任务家族不能由重复运行数替代，泛化判断保留这一限制。
