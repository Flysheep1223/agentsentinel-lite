# 第二轮离线模型与评价方案

制定日期：2026-11-06；基于已完成的训练分区 EDA，尚未查看第二轮测试预测。
本文件先明确分析口径；正式执行前还需生成包含数据、代码、依赖哈希的
`analysis_plan.json`。所有模型与阈值冻结之后才允许独立测试。

## 数据和范围

- 使用 `artifacts/expanded_dataset_v1`，训练诊断依据为 `artifacts/expanded_eda_v2`。
- 原始数据、原标签、20个模板及6/2/2个父家族的分区保持不变。
  第一轮数据与模型产物不改写、不混训；旧 schema 2 接口保持严格校验。
- 仅有效 Session 及全部可决策前缀可进入建模。故障条件、分组ID、批次、
  验证结果与后验诊断均不得作为输入。
- 本轮只进行离线计算。收费采集与在线运行数为0；离线回放结果不冒充实测在线收益。

## 训练与交叉验证

主模型为完整22列特征的 Logistic Regression，主策略为验证误停预算5%。
完整特征KNN、固定规则、步数规则与永不停止为对照。消融仅训练LR，均为预先指定的次要分析，
不按测试结果选择“最终赢家”。

训练时，每个Session按工具步数排序，最多等距抽取6条前缀，不按标签抽样。
拟合使用抽样后的行；`class_weight=balanced` 仍按拟合行的类别分布计算。
等距抽样限定长轨迹的影响，但不保证每个Session具有相同拟合权重。

沿用冻结的3折CV，每折同时留出两个父家族及其全部子模板：

1. incident-01、ticket-00。
2. incident-02、ticket-02。
3. incident-03、ticket-03。

每折只用其他训练家族的抽样前缀拟合预处理与模型；评分使用留出家族的全部可决策前缀。
评分时每条前缀权重为该Session前缀数的倒数，使每个Session权重总和为1。
以3折的Session等权Average Precision均值选择超参数；普通前缀AP另列，不能用于二次选择。
并列时取预先枚举顺序的第一项。不得重新划分折或将同一父家族拆开。

预处理为数值中位数插补及缺失标记、标准化；类别众数插补及One-Hot，忽略未知类别。
全部变换只在当折拟合样本上学习；最终模型用所有训练家族的抽样前缀重新拟合。

候选参数固定如下：

| 模型 | 参数 |
| --- | --- |
| LR | C = 0.1、1、10；class_weight = None、balanced；max_iter=2000；random_state=42 |
| KNN | k = 3、5、9；weights = uniform、distance；欧氏距离；brute；n_jobs=1 |

数值线程上限设为1以避免过量线程影响本机耗时与资源占用。
KNN批量预测可以分块，但不得改变距离、邻居或权重定义。

## 预先定义的特征组

所有特征组都是现有22列allowlist的子集；本轮不增加私有答案特征或任务特定答案规则。

| 组 | 输入变化 |
| --- | --- |
| full | 全部22列 |
| no_tokens | 删除名称包含token及以cost_开头的列；保留步骤和时间 |
| no_errors | 删除名称包含error的列及status、retry_count |
| no_tool_identity | 删除tool和previous_tool |
| no_previous_tool | 只删除previous_tool，检查显式相邻工具信息 |
| no_write_stage | 只删除write_count，检查显式累计写入阶段信息 |
| no_time | 删除elapsed_ms、recent_latency_ms |
| phase_only | 只保留step、tool_calls、write_count、tool、previous_tool、workflow |

这些消融不是完全独立的信息删除实验。例如删除write_count后，工具类别仍可能反映写入阶段；
删除previous_tool后，重复、重试和最近窗口特征仍包含顺序信息。结论应限定为对应显式列的作用。

## 规则、阈值与冻结屏障

固定规则为 step、retry_count、consecutive_errors、total_tokens 的OR组合。
每项候选阈值来自抽样训练前缀的50%、80%、95%分位数，去重、去掉非正值，并允许关闭该项。
步数规则使用所有不同的训练步数，并允许永不停止。
这些候选固定之后，只在验证分区选择最终规则或模型分数阈值。

两个误停预算为5%、10%，分母均为验证集中全部原成功Session；
只要原成功Session出现首次告警，即计误停，包括告警时写入/状态已经完成的情况。
这个严格口径用于选择阈值，不能事后按完成情况放宽。

候选阈值为验证前缀全部不同分数及显式永不停止。
在满足误停预算的候选中，最小化全体验证Session的执行费用；
如果任一候选所需的基线或前缀费用缺失，整次选择统一改用Token，不把未知费用填0。
并列时依次选择误停更少、失败告警更多的候选；仍并列时保留预先枚举顺序。

所有变体、规则和两个预算的政策文件及模型二进制哈希都写入
`all_policies_frozen.json` 后，才可生成测试预测。测试启动标记与产物不得覆盖；
测试结果不能用于修改特征、参数、规则或阈值。

## 评价口径

停止发生在工具返回且仍可继续的前缀上；首先达到阈值的前缀触发停止。
当步模型请求和工具操作已经发生，只扣除之后的资源；第12步不允许告警。

同时报告：

- 全前缀普通AP、ROC AUC、Brier、校准，以及Session等权AP；
  固定第3步预测为主要早期指标，第1/6/9/11步为预先指定的次要指标，均列存活分母。
- Session误停率、失败告警召回、终止前提前步数/Token/时间。
- 告警步严格小于原 `first_violation_step` 才计违规前告警，同一步不计。
  另加顺序错误敏感性口径：对没有额外或缺失写入、只有列表顺序错误的失败，
  纳入私有重放的首次顺序不匹配步。主、敏感性分母分别列出。
- 原成功任务中，停止时尚未满足写入/状态验证的数量，以及已满足验证后停止的数量。
  初始无需写入的任务完成时点为0；必要读取未被验证器独立检查。
- 原失败任务在告警时已经满足写入/状态验证的数量。
  根据停止时状态重放估算完成数变化，并与严格误停口径并列；
  这只是确定性本地状态反事实，不是新增在线实验。
- 全体资源节省、仅失败任务贡献的节省、误停成功任务贡献的节省。
  Token、推理Token、CNY与墙钟时间分别报告；推理Token属于输出子集，不能重复计价。
- 各模板、父家族、工作流、故障条件与终止原因的完整分母、成功/失败、费用和提前量。
- 保持冻结政策，排除仅顺序失败、排除初始无需写入任务的描述性敏感性分析；
  不重训、不重新选阈值。空子集输出明确空计数和null比率。

预测器仅接收特征allowlist；后验完成、违规和顺序证据只能在评价路径关联。
验证诊断仅用于解释及测试前建议，不反向调整阈值。
测试私有诊断必须在全部政策冻结后读取并核对原始文件哈希。

## 不确定性、监控开销和后续建议

以完整父家族为重采样单位进行500次描述性bootstrap，种子42。
同一家族的两个子模板、全部任务实例、故障条件和重复运行一起抽取。
测试仅有两个父家族，区间只能说明有限家族组成的变化，不能作为广泛泛化保证。
无成功、无失败、无违规或费用不全的子集使用null，不将缺失指标解释为0。

评分耗时在训练样本上用固定最多24次单行请求测量中位数，含DataFrame构造、预处理与预测。
不包含原始日志特征提取或调度开销；将评分时间加入回放墙钟估计。
监控人民币单价固定为0，因此不能据此声称监控无实际成本。永不停止对照无需评分开销。

在查看测试结果之前，只依据full/LR@5%的验证结果记录后续在线研究建议：
必须同时满足误停预算、有失败告警、已知CNY节省为正、至少一次严格违规前告警，
且按写入/状态反事实估算完成数没有下降，才记为值得另行设计在线验证；
否则记为暂缓。这个记录不授权也不启动任何收费请求。

## 执行检查

先修复与验证部分费用缺失、空子集等评价边界，再冻结代码。
正式产物应包括源码快照、依赖版本、输入封印、每折评分、全部候选阈值曲线、
训练与验证预测、全部政策冻结记录、测试启动记录、逐Session/前缀测试预测、
分组/消融/固定早期评价、图表、报告和最终完整性封印。
